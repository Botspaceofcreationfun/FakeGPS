# GPS Fake Pro 使用说明（中文）

无广告、无统计的 Android 模拟定位工具，用于测试依赖定位的应用与模拟路线。
使用 Kotlin + Jetpack Compose + OpenStreetMap（osmdroid）+ Room/DataStore。
无需 Google Maps 密钥、无需付费地理编码、无需账号。

> 本工具是调试工具，仅使用 Android 官方模拟定位机制（开发者选项 → “选择模拟位置信息应用”）。
> 它不隐藏 `isFromMockProvider()` 的模拟标记，不依赖 root，也不绕过任何定位完整性校验。

## 编译

- 环境：JDK 17、Android SDK（platform 35）、Gradle 8.9（已含 wrapper）。
- Android Studio：打开 `GPSFakePro` 目录直接运行。
- 命令行：`./gradlew :app:assembleDebug`，产物为
  `app/build/outputs/apk/debug/app-debug.apk`。
- 最低系统版本：Android 8.0（API 26）；编译/目标版本：Android 15（API 35）。

## 首次使用（一次性，约 1 分钟）

1. 设置 → 关于手机 → 连续点击“版本号”7 次，进入开发者模式。
2. 设置 → 系统 → 开发者选项（路径因设备而异）。
3. 找到“选择模拟位置信息应用”，选择 **GPS Fake Pro**。
4. 回到应用开始模拟即可。
   - 部分厂商会改写该设置项名称（如“允许模拟位置”“Mock location”等）；找不到即表示该系统版本不支持模拟定位。
   - Android 13 及以上请允许通知权限，便于后台查看模拟状态。

## 基本用法

- **定点模式**：地图页点选位置（或搜索 / 手动输入坐标）→ 展开底部面板 → “开始定点”。
  运行中可实时调整上报速度、航向、海拔、精度与更新间隔；点红色“停止”结束。
- **路线模式**：“路线”页 → 新建/编辑路线 → 添加途经点（可用地图当前所选点或手动坐标），
  支持上移/下移、编辑、删除 → 设置速度与途经点暂停 → 保存或“开始模拟”。
  地图会显示整条路线（灰）与已行进部分（蓝），标记随位置移动，面板显示进度/距离/暂停倒计时。
  路线跑完后会持续上报最后位置，直到停止或重新开始。
- **GPX**：支持导入/导出 GPX 1.1；文件或坐标无效时给出明确错误；同名路线导入时自动改名
  （“名称 (2)”），绝不覆盖已有路线。
- **语言**：设置页可在“跟随系统 / English / 中文”间切换。

## 权限与隐私

无广告、无统计、无追踪；不申请真实定位、存储等权限；所有收藏、路线、最近位置均保存在本机，
可在设置中清除。联网仅用于地图瓦片与地点搜索。地图瓦片遵循 OpenStreetMap 使用政策，
不提供批量离线下载。

## 已知限制

- 路线为途经点之间的直线插值，不沿真实道路。
- 仅支持存在“模拟定位应用”开发者选项的设备。
- 检测 `isFromMockProvider()` 的应用会识别出模拟位置——这是刻意保留的诚实行为。
